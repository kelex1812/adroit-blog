## Deep Dive

**One definition, many surfaces.** OmniScripts embed on Lightning pages (App Builder), Experience Cloud sites, mobile apps, and standalone web contexts. A single script definition serves across all channels.

**Pass context to pre-populate.** Hand record context and parameters (for example, `recordId`) into the script so it opens pre-populated. Scripts read context via public attributes or URL parameters.

**Channel nuances.** Experience Cloud needs licensing, mobile needs responsive steps and touch-friendly inputs, and embedded web may need auth context.

**Auto-generated LWC wrappers.** Auto-generated wrappers make embedding drag-and-drop in App Builder and Experience Builder.

**Reuse-first design.** A well-designed OmniScript with parameterized context embeds anywhere without duplication.

## Configuration Walkthrough

1. Design the script to accept context parameters.
2. Embed via LWC wrapper on Lightning pages.
3. Embed on Experience Cloud / mobile as required.
4. Verify context flows in each channel.

## Exam Traps

- Embedding without passing record context. The flow opens empty.
- Promising a portal without the Experience Cloud license.
- Designing desktop-only layouts that break on mobile.

**Q1.** Where can an OmniScript be embedded?

A. Only inside other OmniScripts<br/>
B. Lightning pages, Experience Cloud, mobile, and web channels<br/>
C. Only in Aura apps<br/>
D. Only on desktop

<details>
  <summary>Show answer</summary>
  **Correct: B.** OmniScripts embed across Lightning, Experience Cloud, mobile, and web.
</details>

**Q2.** What ensures an embedded OmniScript opens pre-populated for the selected record?

A. Passing context (e.g., recordId) into the script<br/>
B. Hardcoding values<br/>
C. A FlexCard state<br/>
D. A report

<details>
  <summary>Show answer</summary>
  **Correct: A.** Context parameters let the script pre-fill from the host page.
</details>

**Q3.** What makes embedding drag-and-drop on App Builder pages possible?

A. Auto-generated LWC wrappers<br/>
B. Apex classes<br/>
C. Manual HTML<br/>

<details>
  <summary>Show answer</summary>
  **Correct: A.** OmniScripts generate LWC wrappers for App Builder / Experience Builder.
</details>

## Exam Tip

Parameterize context, embed via LWC wrapper, verify per channel. One script, many surfaces.
